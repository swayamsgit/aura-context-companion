Privacy, honestly

Your people, notes and routine are saved in this browser on this device. They are not uploaded, not synced and not encrypted. Clearing browser data erases them, so download a backup now and then. Anyone who can open this browser can read them.

Aura makes no network calls with your notes. Dictation, if you use it, is handled by your browser's own speech service.

Use everyday information only. Aura is not a medical device and must not be used to decide medication, treatment, emergencies or whether someone is safe alone.

ABOUT AURA

What Aura is,
and is not.

What it does

  • Context cards for people you choose, with optional photos
  • A daily routine with due and done states
  • Daily notes by typing or browser dictation, with search
  • Evidence-linked check-in with a review gate
  • Copy, WhatsApp, email or print, always started by you
  • Text size, high contrast, read aloud
  • Backup and restore, offline use, install to home screen

What it does not do

  • No smart glasses, Bluetooth or wearable capture
  • No face recognition and no guessing who someone is
  • No emotion, confusion or health-state detection
  • No medication advice, diagnosis or emergency monitoring
  • No encryption, accounts or cloud sync
  • No automatic messages to anyone
  • No clinical testing

Optional Meta model

The source includes an adapter for Meta's model API, off by default and only usable on a self-hosted server with an approved key. It has not been run live. This site does not use it. The code is on GitHub.
