# Aura

A non-clinical contextual memory companion.

**[Open the live app](https://aura-companion-5hf.pages.dev)**

Source, setup, privacy limits and tests are in [`aura-context-companion/`](aura-context-companion/).

```sh
cd aura-context-companion
npm test
npm start
```

The hosted version stores data in your browser and does not use the optional Meta API.
